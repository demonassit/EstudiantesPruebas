# cecyt9-pruebas

Prácticas de Pruebas de Software, sobre el proyecto real de gestión de cursos/talleres del CECyT9. Este repo **no contiene código de la aplicación** (eso vive en `cecyt9-proyecto` de tu equipo), pero sí acumula los artefactos propios de esta materia: plan de pruebas, casos de prueba y colección Postman.

## Estructura

```
docs/guia-git-equipo.md               → Git para trabajo en equipo + Práctica 0
artefactos/                           → plan de pruebas, casos de prueba, colección Postman (se van agregando aquí semana a semana)
parcial-1-landing-page/               → semanas 1-5 · corte: estrategia/plan de pruebas
parcial-2-bd-supabase-auth/           → semanas 6-10 · corte: pruebas de integración sobre CRUD+login
parcial-3-jwt-dashboard-websockets/   → semanas 11-15 · corte: informe final de calidad ISO 9126
```

Cada carpeta `semana-XX/` trae un `README.md` con: tema oficial, objetivo, prerrequisitos, actividad y entregable. La rúbrica de evaluación la tiene tu docente por separado.

## Cómo entregar

Los artefactos de esta materia (plan de pruebas, casos de prueba, exports de Postman) sí se suben directamente a la carpeta `artefactos/` de este repo. Cuando una prueba se ejecuta **contra** el proyecto real, referencia el commit/versión de `cecyt9-proyecto` que se probó.

## Antes de la Semana 1

Haz la **Práctica 0** de `docs/guia-git-equipo.md` con tu equipo — es la práctica de Git donde provocan y resuelven un conflicto de merge real, antes de que les pase en una entrega que sí cuenta.
