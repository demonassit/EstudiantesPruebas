# Semana 6 (28 sep-2 oct) — Pruebas de Software

**Tipo:** Individual

**Tema oficial:** inicio de U2·AE2 Casos de prueba de unidad para los módulos en construcción.

**Objetivo:** redactar casos de prueba de unidad para una función aislada (todavía no el CRUD real), aplicando el formato oficial (propósito, prerrequisitos, indicadores, valores de entrada, pasos de ejecución, resultado esperado/obtenido, estado de la prueba).

**Prerrequisitos:** Parcial 1 completo.

**Actividad:** escribir 3 casos de prueba de unidad para una función simple de validación (ej. "validar formato de correo" o "validar longitud mínima de contraseña"), sin depender aún del proyecto real.

**Entregable:** 3 casos de prueba de unidad en formato oficial.

**Archivo base:** `base/casos-prueba-unidad.md` (3 casos, campos vacíos).
