# Semana 9 (19-23 oct) — Pruebas de Software

**Tipo:** Integradora

**Tema oficial:** inicio de Unidad 3 — Aplicación de pruebas: herramientas y pruebas unitarias.

**Objetivo:** ejecutar (ya no solo diseñar) los casos de prueba de unidad sobre el CRUD de usuarios real que Web entregó en su semana 8-9, usando una herramienta de pruebas unitarias (ej. Jest) o pruebas manuales bien documentadas si aún no se usa framework.

**Prerrequisitos:** semanas 6-8; CRUD de usuarios ya migrado a Supabase (entregado por Web en su semana 9).

**Actividad:** ejecutar los casos de prueba diseñados contra los endpoints reales del CRUD; documentar resultado esperado vs. obtenido.

**Entregable:** reporte de ejecución de pruebas unitarias sobre el CRUD real + colección Postman inicial con las peticiones probadas.

**Archivos base:** `base/coleccion-postman.json` (colección vacía, impórtala en Postman) + `base/reporte-ejecucion.md` (plantilla de 3 casos).

**Ejercicio complementario (opcional):** `base/ejercicio-unitarias-jest/` — lleva tus casos de prueba de unidad a código real con Jest. Ver su `README-ejercicio.md`.
