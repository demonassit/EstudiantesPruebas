# Semana 11 (2-6 nov) (*) — Pruebas de Software

**Tipo:** Individual

**Tema oficial:** inicio de U3·AE2 Métricas de calidad ISO 9126 (funcionalidad, confiabilidad, usabilidad, eficiencia, mantenibilidad, portabilidad).

**Objetivo:** conocer las 6 características de calidad ISO 9126 y cómo se miden, aplicándolas primero a un ejemplo genérico antes del proyecto real.

**Prerrequisitos:** Parcial 2.

**Actividad:** ejercicio aislado — evaluar (con una rúbrica simple) las 6 características ISO 9126 sobre una aplicación conocida cualquiera, como entrenamiento antes de evaluar el proyecto propio.

**Entregable:** tabla de evaluación ISO 9126 de la app de ejemplo, con justificación por característica.

**Archivo base:** `base/evaluacion-iso9126-ejemplo.md` (6 secciones vacías).
