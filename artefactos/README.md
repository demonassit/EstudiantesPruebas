# Artefactos de Pruebas de Software

Aquí va todo lo que el equipo produce en esta materia y que no es código de la app: plan de pruebas, casos de prueba, colección de Postman (export `.json`), reportes de ejecución.

Sugerencia de organización (ajústala si tu equipo prefiere otra):

```
artefactos/
├── plan-de-pruebas.md
├── casos-de-prueba/
│   ├── parcial-1.md
│   ├── parcial-2.md
│   └── parcial-3.md
├── postman/
│   └── cecyt9.postman_collection.json
└── reportes/
    ├── corte-1.md
    ├── corte-2.md
    └── corte-3.md
```

## Plantillas de Excel

En `docs/` hay 2 plantillas listas para llevar el control de tus casos (una fila por caso, con menú desplegable de estado):

- `docs/plantilla-casos-prueba-unitaria.xlsx` — para `casos-de-prueba/` (semana 6-7 y el ejercicio de Jest de semana 9).
- `docs/plantilla-pruebas-integracion.xlsx` — para `reportes/` (semana 10 y el ejercicio de Jest+Supertest).

Cópialas aquí adentro y guárdalas con el nombre que prefieras (ej. `casos-de-prueba/parcial-2.xlsx`).
